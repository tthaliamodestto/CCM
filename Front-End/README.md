# CCM — Calculadora de Conversão Metalúrgica


## Sobre o projeto

O **CCM (Calculadora de Conversão Metalúrgica)** é um sistema desenvolvido como Trabalho de Conclusão de Curso (TCC) do curso Técnico em Desenvolvimento de Sistemas da Escola SENAI "Dr. Celso Charuri" — Unidade Sumaré.

O sistema tem como objetivo auxiliar profissionais e usuários da área de usinagem na realização de cálculos relacionados à fabricação de peças, reduzindo a necessidade de cálculos manuais e facilitando o processo de obtenção dos resultados.

Este repositório corresponde ao **Front-end** do projeto.

---

## 🎯 Objetivo

O objetivo do sistema é facilitar o processo de cálculo utilizado na área de usinagem, permitindo que o usuário informe os dados de uma peça e obtenha os resultados dos cálculos de forma rápida e organizada.

O sistema busca:

- Reduzir cálculos manuais;
- Diminuir possíveis erros de cálculo;
- Agilizar o processo de usinagem;
- Organizar as informações das peças;
- Facilitar a visualização dos resultados.

---

## ⚙️ Funcionalidades

O Front-end possui as seguintes funcionalidades:

- Cadastro de peças;
- Cadastro e seleção de materiais;
- Cálculo de volume;
- Cálculo de peso;
- Conversão de medidas;
- Definição de parâmetros de corte;
- Cálculo de rotação;
- Cálculo de avanço;
- Cálculo de profundidade de corte;
- Cálculo do tempo de usinagem;
- Seleção de máquina;
- Seleção de ferramenta;
- Exibição dos resultados;


---

##  Cadastro de peças

O sistema permite cadastrar as informações necessárias para realizar os cálculos da peça.

Entre os dados disponíveis estão:

- Nome da peça;
- Código da peça;
- Material;
- Preço por quilograma;
- Formato da peça;
- Comprimento;
- Largura;
- Altura;
- Diâmetro;
- Densidade;
- Operação;
- Máquina;
- Ferramenta;
- Velocidade de corte;
- Avanço;
- Profundidade de corte.

Após o fornecimento dessas informações será possivel realizar o calculo do peso, volume e tempo, com esses dados será possivel calcular o valor e a margem de lucro para fabricação de um peça.

---

## 🔩 Materiais

O sistema possui diferentes materiais que podem ser utilizados nos cálculos.

### Materiais disponíveis

- Aço SAE 1020;
- Aço SAE 1045;
- Aço inox 304;
- Aço inox 316;
- HSS;
- Alumínio 6061;
- Alumínio 7075;
- Bronze;
- Latão;
- Ferro fundido GG25;
- Nylon;
- PTFE.

Cada material possui informações utilizadas nos cálculos, como densidade e preço por quilograma.
Apartir desses dados é possivel cadastrar qualquer material.

---

## 📐 Cálculos

O sistema realiza cálculos relacionados às dimensões e características da peça.

### Volume

O volume é calculado de acordo com o formato selecionado para a peça e suas respectivas dimensões.

### Peso

O peso é obtido utilizando o volume calculado e a densidade do material selecionado.

### Parâmetros de corte

O sistema permite informar os parâmetros utilizados no processo de usinagem, como:

- Velocidade de corte;
- Avanço;
- Profundidade de corte;
- Rotação.

### Tempo de usinagem

O sistema utiliza os dados informados pelo usuário para calcular o tempo estimado necessário para realizar a operação de usinagem.
